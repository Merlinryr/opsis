Write a research note for: $ARGUMENTS

Steps:
1. Check `docs/research/` for an existing note on the same topic; update it instead of duplicating.
2. Research with the available tools. Prefer primary sources (official docs, papers, repo code). Record each source as a link or paper reference.
3. Write `docs/research/YYYY-MM-DD_SHORT_TITLE.md` using the template below. Short sentences. No filler.
4. If the note leads to a decision or new work, link it from the relevant milestone record in `docs/milestones/`.

Template:

```markdown
# Title

**Date:** YYYY-MM-DD
**Status:** Open | Concluded | Superseded by [link]

## Description
One or two sentences: what this is about.

## Problem
The question to answer, in one sentence.

## Research
- Finding, with source: [Title](url) or Author, *Title*, venue, year

## Conclusion
- Answer in one or two sentences.
- Decision or next step, with link to milestone (or none).
```
